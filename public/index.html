Record of Cleared Orders

Agentic KG Holdings

RCO is the Record of Cleared Orders. A receipt is written when a gate clears an agentic order: {decision_id, gtin, market, actor_class, rule_version, cleared_at, writer, prev_hash, hash, sig, kid}. Each receipt is hash-chained to the one before it and signed by the office key. Two tools, nothing else: write_receipt, authenticated with one bearer token per writer, returns the decision id; verify_receipt, public, returns the receipt, its signature and the key to check it.

§1 THE RECORD

One receipt per cleared order

  • decision_id — the gate's id for the decision; the key a receipt is retrieved by.
  • gtin · market · actor_class · rule_version · cleared_at — what was cleared, where, for whom, under which rule, when.
  • writer — the gate that wrote it, named by its token.
  • prev_hash · hash — the chain: each receipt's hash covers the one before it; the first receipt's prev_hash is sha256 of nothing.
  • sig · kid — the office's Ed25519 signature over the hash, and the key id that checks it on the keyring.
§2 THE TWO TOOLS

Model Context Protocol (MCP) door

Door: https://mcp.rco-a2a.ai/mcp — streamable HTTP, stateless, JSON-RPC 2.0, typed errors.

  • write_receipt — Authorization: Bearer <writer token>. Arguments gtin, market, actor_class, rule_version, cleared_at (and decision_id when the gate minted one). Returns the decision_id. Idempotent on decision_id.
  • verify_receipt — public. Argument decision_id. Returns the receipt, its chain position, its signature and the public key (JWK) that checks it.
§3 VERIFY

The verify URL

https://rco-a2a.ai/receipts/{decision_id} — the same answer as verify_receipt, over GET, for any client. Keyring: /.well-known/jwks.json. Machine register: /llms.txt. Agent Card: /.well-known/agent-card.json.
